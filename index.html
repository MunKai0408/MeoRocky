1. Chọn file

File chỉ được đọc và xử lý trong trình duyệt của bạn. Bản web giới hạn file ≤2GB; file lớn hơn hãy dùng bản iSH. Lưu ý: file gần 2GB vẫn có thể làm Safari trên iPhone văng tab vì RAM (tab Safari chỉ dùng được khoảng 1–1,5GB) — với file lớn nên dùng bản iSH cho chắc. Lần mở trang đầu cần mạng để tải Pyodide; sau đó xử lý hoàn toàn trên máy bạn, trừ khi bạn bật dịch Google ở tab Dịch (cần mạng).

Danh sách entry trong file

Liệt kê các entry của ZIP/IPA (tên, loại, kích thước).

Inspect Unity

Đọc bundle .unity3d hoặc file .assets độc lập bằng parser thuần của PB3 (UnityFS v8, SerializedFile v23). Không dùng UnityPy trên web. Nếu file đang chọn là ZIP/IPA thì trang liệt kê các bundle/.assets bên trong để bạn chọn 1 cái inspect trực tiếp. Asset nhị phân (texture/âm thanh): chỉ đọc, dùng bản iSH.

Trích xuất text

Chạy pipeline trích xuất đầy đủ của PB3, xuất các bảng key-value ra file JSON. Kết quả tải về dạng extract.zip.

Dịch (Google + từ điển offline)

Chỉ dịch VALUE, giữ nguyên KEY. Bật Google Translate để dịch mọi chuỗi qua Google (cần mạng; 1 chuỗi/request, cách 0,4 giây nên file lớn sẽ chậm — file vài nghìn chuỗi có thể mất hàng giờ, dùng bản iSH cho nhanh). Nếu Google không dùng được (mất mạng, bị giới hạn tốc độ, trình duyệt chặn CORS) thì tự động thử MyMemory rồi dùng từ điển offline (~40 cụm từ game thông dụng) và báo rõ lý do.

Để trống = gọi trực tiếp Google. Có proxy thì dịch qua proxy (cache + giới hạn cứng 500.000 ký tự/tháng, hết hạn mức tự rơi về MyMemory + từ điển offline, không phát sinh phí). Cần tài khoản Cloudflare + API key Google — xem hướng dẫn trong repo (cloudflare/README.md). Mở trang Kiểm tra dịch để thử trực tiếp Google / proxy / MyMemory trên máy này trước khi dịch file lớn.

Hoặc dán JSON key-value vào ô dưới:

Mod — patch TextAsset (menu [1] bản iSH)

Patch 1 chuỗi trong 1 TextAsset của file Unity đã chọn (bundle .unity3d, .assets độc lập, hoặc entry trong IPA/ZIP qua vpath dạng a::b). Mặc định chỉ chạy thử (dry-run): không ghi file nào. Chỉ khi bạn bấm nút “Patch và ghi file” thì đơn vị đã patch mới được tải về — file gốc không bao giờ bị ghi đè. Output là đơn vị nhỏ nhất đã patch (bundle/.assets), không phải IPA đóng gói lại. Asset nhị phân (texture/âm thanh): chỉ đọc, dùng bản iSH.

Batch — chạy hàng loạt (menu [4] bản iSH)

Chạy TUẦN TỰ từng game — bản web không có threading nên không có chế độ song song (bản iSH có jobs>1, bản web luôn jobs=1). Mỗi game cô lập: lỗi một game không dừng cả lô. Mặc định chạy thử trước (dry-run): bỏ dấu chọn mới ghi thật. Manifest JSON hoặc CSV (cột: path, mode, locale, old, new, file, object). Chọn tất cả file game ở dưới (đường dẫn trong manifest chỉ cần đúng tên file). Checkpoint được lưu tự động vào trình duyệt của bạn sau mỗi lần chạy — bấm “Nạp checkpoint đã lưu” rồi chạy lại với “Tiếp tục từ checkpoint” để bỏ qua game đã xong.

Kho tri thức game — KB (menu [3] bản iSH)

KB lưu fingerprint + lựa chọn đã dò của game để lần sau tái dùng (chỉ lưu hash/kích thước/vai trò — không lưu nội dung game hay bản dịch). Giới hạn thật: KB chỉ sống trong phiên này — tải lại trang là mất hết, trừ khi bạn tải file KB về (nút dưới) rồi nhập lại bằng nút “Nhập KB” trong phiên mới.

Nhập KB hợp nhất các game trong file vào KB của phiên này (game trùng bundle id sẽ bị ghi đè). Profile nhập vào chỉ là gợi ý — hash chưa được đối chiếu với file game nên cần dò lại khi dùng.

Ma trận hỗ trợ

Sinh từ dữ liệu thật của PB3: registry (maturity hiệu lực), bảng container/Unity của sdk, cột “số game đã test” từ KB của phiên. Không hardcode. Lưu ý: cột “ngày test” hiện “chưa có” vì bản web không kèm file bằng chứng tests/corpus/*.json (chỉ có trên cây iSH); không có mục nào đạt M4.

Nén / giải nén IPA

Nén solid LZMA kiểu WinRAR. File nén ra là bản lưu trữ (.tar.xz), không phải IPA cài trực tiếp. Giải nén file .tar.xz để khôi phục file gốc (giữ nguyên tên gốc) — chọn đúng file .tar.xz đã nén ra rồi bấm Giải nén.

Công cụ font

Quét font TTF xem thiếu bao nhiêu ký tự tiếng Việt (142 mục chuẩn: 134 chữ cái + 8 dấu kết hợp), gộp glyph từ font Be Vietnam Pro đi kèm, hoặc lấy luôn font đi kèm về dùng. Giới hạn thật: atlas SDF của TextMeshPro không tái tạo được.

Chẩn đoán (chỉ đọc)

Inventory + hex dump (512 byte đầu) + quét chuỗi ASCII trong file. Asset nhị phân (texture/âm thanh): chỉ đọc, dùng bản iSH.

Giới hạn của bản web (đo thật, xem README)

  • Không dùng UnityPy (không cài được trên Pyodide — thiếu wheel etcpak). Inspect Unity dùng parser thuần của PB3.
  • Batch chỉ chạy tuần tự (không có threading trên web, không có chế độ song song như bản iSH); extract cũng chạy tuần tự.
  • KB chỉ sống trong phiên — tải lại trang là mất, trừ khi tải file KB về rồi nhập lại bằng nút “Nhập KB (.sqlite)” trên tab KB.
  • Mod chỉ xuất đơn vị nhỏ nhất đã patch (bundle/.assets), không đóng gói lại IPA; mặc định dry-run, chỉ ghi khi bạn bấm nút ghi rõ ràng.
  • Ma trận hỗ trợ: cột “ngày test” hiện “chưa có” vì bản web không kèm file bằng chứng tests/corpus/*.json.
  • Dịch Google cần mạng; Google có thể giới hạn tốc độ (HTTP 429) hoặc trình duyệt chặn CORS — khi đó tự động thử MyMemory rồi dùng từ điển offline và báo rõ lý do. Chưa thử dịch Google trên Safari thật. Có thể cấu hình proxy Cloudflare Worker (ô URL proxy ở tab Dịch, xem cloudflare/README.md) để tránh CORS/429 — proxy có hạn mức cứng 500.000 ký tự/tháng, hết hạn mức tự rơi về MyMemory + offline, không phát sinh phí.
  • Asset nhị phân (texture/âm thanh): chỉ đọc, dùng bản iSH. Bản web xem được tên, kích thước, hex, chuỗi text trong asset, nhưng không giải mã texture (DXT/ASTC/ETC2/PVRTC) hay âm thanh (Vorbis/MP3/AAC) để xem trước — xem texture/nghe âm thanh thì dùng bản iSH.
  • File đầu vào tối đa 2GB trên web (bằng bản iSH); file gần 2GB vẫn có thể làm Safari trên iPhone văng tab vì RAM.
  • Chưa thử trên iPhone thật — tốc độ và RAM trên Safari di động chưa đo.
