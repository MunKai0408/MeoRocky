1. Chọn file

File chỉ được đọc và xử lý trong trình duyệt của bạn. Bản web giới hạn file ≤2GB; file lớn hơn hãy dùng bản iSH. Lưu ý: file gần 2GB vẫn có thể làm Safari trên iPhone văng tab vì RAM (tab Safari chỉ dùng được khoảng 1–1,5GB) — với file lớn nên dùng bản iSH cho chắc. Lần mở trang đầu cần mạng để tải Pyodide; sau đó xử lý hoàn toàn offline (trừ khi bạn bật dịch Google — bản web v1 chưa có, chỉ dịch bằng từ điển offline).

Danh sách entry trong file

Liệt kê các entry của ZIP/IPA (tên, loại, kích thước).

Inspect Unity

Đọc bundle .unity3d hoặc file .assets độc lập bằng parser thuần của PB3 (UnityFS v8, SerializedFile v23). Không dùng UnityPy trên web.

Trích xuất text

Chạy pipeline trích xuất đầy đủ của PB3, xuất các bảng key-value ra file JSON. Kết quả tải về dạng extract.zip.

Dịch (từ điển offline)

Chỉ dịch VALUE, giữ nguyên KEY. Bản web v1 chỉ có từ điển offline (~40 cụm từ game thông dụng); dịch Google chưa có trên web.

Nén / giải nén IPA

Nén solid LZMA kiểu WinRAR. File nén ra là bản lưu trữ (.tar.xz), không phải IPA cài trực tiếp — dùng nút Giải nén để khôi phục IPA gốc.

Công cụ font

Quét font TTF xem thiếu bao nhiêu ký tự tiếng Việt (112 ký tự chuẩn), gộp glyph từ font Be Vietnam Pro đi kèm, hoặc lấy luôn font đi kèm về dùng. Giới hạn thật: atlas SDF của TextMeshPro không tái tạo được.

Chẩn đoán (chỉ đọc)

Inventory + hex dump (512 byte đầu) + quét chuỗi ASCII trong file.

Giới hạn của bản web (đo thật, xem README)

  • Không dùng UnityPy (không cài được trên Pyodide — thiếu wheel etcpak). Inspect Unity dùng parser thuần của PB3.
  • Không chạy được tính năng cần threading (batch song song); extract chạy tuần tự.
  • File đầu vào tối đa 2GB trên web (bằng bản iSH); file gần 2GB vẫn có thể làm Safari trên iPhone văng tab vì RAM.
  • Chưa thử trên iPhone thật — tốc độ và RAM trên Safari di động chưa đo.
