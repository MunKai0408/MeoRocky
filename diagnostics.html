Kiểm tra dịch — BearTea

Mở trang này trên Safari iPhone thật, bấm từng nút kiểm tra, rồi bấm “Sao chép kết quả” để gửi lại. Trang này không cần Pyodide — chỉ dùng fetch() trực tiếp, nên biết chắc Google / proxy / MyMemory có gọi được từ máy này không trước khi dịch file lớn. ← Về trang chính

1. Môi trường trình duyệt

2. Dịch trực tiếp từ trình duyệt (không qua proxy)

Google trực tiếp hay bị 429 / chặn CORS tùy IP (IP máy chủ từng bị Google trả 429 + trang Sorry; IP mạng di động/dân cư thường dịch được). MyMemory miễn phí, không key, giới hạn ~500 ký tự/request.

3. Dịch qua proxy Cloudflare Worker

Proxy cần Joseph deploy trước (xem cloudflare/README.md trong repo). Dán URL worker vào ô dưới rồi bấm kiểm tra — phải thấy ok: true, provider: "google". Nút “Lưu URL proxy” ghi URL vào trình duyệt để tab Dịch ở trang chính dùng luôn.

4. LibreTranslate (tùy chọn, mặc định tắt)

Bước dự phòng sau MyMemory. Bản public libretranslate.com hiện yêu cầu API key (lấy ở portal.libretranslate.com, gói trả phí) — không key thì nút dưới sẽ báo HTTP 400, đó là giới hạn của nhà cung cấp, không phải lỗi tool. Tự host LibreTranslate (miễn phí, mã nguồn mở) thì dán URL instance của bạn, thường không cần key. Nút “Lưu LibreTranslate” ghi endpoint + key vào trình duyệt để tab Dịch ở trang chính dùng luôn.
